# HP Klar Pro 2.0

Vollständige Next.js-Neufassung mit:

- neuem HP-Klar-Logo
- Premium-Dashboard
- responsiver Sidebar und Topbar
- interaktivem Zellatlas
- Lern-, Entdecken- und Prüfungsmodus
- Design-System und wiederverwendbaren UI-Komponenten

## GitHub-Upload

Diese ZIP ist als vollständiger Ersatz für die Foundation gedacht.

1. ZIP entpacken.
2. Im GitHub-Repository `hp-klar-pro` auf **Add file → Upload files** gehen.
3. Den gesamten entpackten Inhalt hochladen.
4. Bei gleichnamigen Dateien werden die alten Versionen ersetzt.
5. Commit-Nachricht: `HP Klar Pro 2.0 installieren`
6. Nach dem Commit veröffentlicht Vercel automatisch neu.

## Wichtiger Hinweis

Vorher am besten unter **Code → Download ZIP** eine Sicherung des bisherigen Repositorys herunterladen.
