# HP Klar Pro – Foundation 1.0

Next.js/TypeScript-Grundversion mit 16 individuellen Zellaufbau-Lektionen, Suche, interaktivem Atlas, Quiz-Erklärungen, Karteikarten und lokaler Wiederholungsplanung.

## Start
```bash
npm install
npm run dev
```
Dann http://localhost:3000 öffnen.

## GitHub/Vercel
Neues Repository `hp-klar-pro` anlegen, Projektinhalt hochladen und in Vercel importieren.
